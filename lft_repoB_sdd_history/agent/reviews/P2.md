# P2 Review Findings

### GE-Act runtime dependencies and launcher are not vendored

- Severity: P2
- Status: Open
- File: [VENDORED_FROM.md](../../ge_act/VENDORED_FROM.md#L4)
- Problem: The manifest claims `data/` was vendored and refers to a scripts helper, but neither `ge_act/data/` nor `ge_act/scripts/` exists, and no GE-Act requirements lock is present.
- Impact: A checkout that has the code can still choose an incompatible Python environment or launch from the wrong working directory. The base environment currently fails the LTX import because its Transformers/PEFT combination is incompatible.
- Evidence: The dedicated local `ge-act` environment imports LTX, while the base environment raises an import error for `HybridCache`; the original GE source provides `requirements.txt` and `scripts/train.sh`, but this subtree does not.

### Dataloader performance settings are declared but ignored

- Severity: P2
- Status: Open
- File: [ge_trainer.py](../../ge_act/runner/ge_trainer.py#L241)
- Problem: The config declares `pin_memory: true`, but `prepare_dataset` does not pass it to `DataLoader`; it also has no persistent-worker or prefetch configuration.
- Impact: Host-to-device transfer and worker startup can become avoidable bottlenecks once online SigLIP2 and the larger cross-attention branch increase step cost.
- Evidence: Lines 241-247 pass only dataset, shuffle, batch size, worker count, and multiprocessing context.

### Rank-zero dataset logging condition is impossible

- Severity: P2
- Status: Open
- File: [__init__.py](../../ge_act/utils/__init__.py#L130)
- Problem: `zero_rank_print` requires distributed mode to be both uninitialized and initialized in the same boolean expression.
- Impact: Dataset discovery, cache, and scale messages are always suppressed, making path and sample-count failures harder to diagnose.
- Evidence: `(not dist.is_initialized()) and (dist.is_initialized() and dist.get_rank() == 0)` can never evaluate true.

### No regression tests cover the semantic LTX contract

- Severity: P2
- Status: Open
- File: [transformer_ltx_multiview.py](../../ge_act/models/ltx_models/transformer_ltx_multiview.py#L454)
- Problem: There are no tests for zero-gate base parity, view isolation, separate query/key RoPE, nine-to-four keyframe timing, frozen SigLIP2 exclusion, differential optimizer groups, checkpoint round trips, CFG duplication, or gradient-checkpoint compatibility.
- Impact: Shape-correct implementations can still regress camera ordering, temporal meaning, pretrained output parity, or distributed training behavior.
- Evidence: The repository has Cosmos/FastWAM semantic tests, but no tracked test targets the GE-Act LTX transformer or trainer semantic interface.
